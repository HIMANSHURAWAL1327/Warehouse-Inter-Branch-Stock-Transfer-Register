# Warehouse-Inter-Branch-Stock-Transfer-Register
oops lab project

Problem statement:-
Two warehouse branches maintain stock in separate classes. A friend function moves quantities from one branch to the other after verifying availability and transfer limits. A static member records the total number of transfers and a static function prints transfer statistics. Failed transfers throw exceptions with clear reasons.

Problem Objective:-
Use friend functions and static members for operations that span multiple objects and classes.

Key Functionality:-
1. Create BranchA and BranchB with private stock arrays.
2. Write a friend function to transfer stock in either direction.
3. Track total transfers and quantity moved with static members.
4. Print transfer statistics using a static member function.
5. Throw exceptions for insufficient stock or unknown item code

OOPS Concept:-
Classes & Objects, Constructors, Exception Handling, Array of Objects,Friend Functions, Static Members
